# Instapro

MVP социальной сети для обмена фотографиями

## Реализованный функционал

### Основные функции
- Авторизация и регистрация пользователей с загрузкой аватарок
- Просмотр ленты постов всех пользователей
- Добавление новых постов с изображениями и описанием
- Просмотр постов конкретного пользователя
- Система лайков с мгновенным обновлением
- Форматирование дат постов в относительном формате

### Технические особенности
- Модульная архитектура приложения
- Компонентный подход к разработке
- Работа с REST API
- Загрузка изображений в облачное хранилище
- Динамическое обновление контента без перезагрузки страницы
- Локальное хранение данных пользователя
- Обработка ошибок и валидация форм

### Интерфейсные улучшения
- Адаптивный и интуитивный интерфейс
- Информативные сообщения об ошибках
- Состояния загрузки для всех операций
- Интерактивные элементы с hover-эффектами
- Красивое отображение времени публикации
